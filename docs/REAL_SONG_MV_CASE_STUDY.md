# 実曲MVの改稿事例｜今日を抱いて帰る

yuta nishigakiの実曲MV（3分16.40秒）で、作者が気に入った場面絵と音声を使いながら、歌詞演出と一部の動作を改稿した。制作には曲専用のPythonスクリプトとFFmpegを使用した。

## 作者の指示が映像にどう反映されたか

| 改稿 | 編集対象 | 確認したこと |
| --- | --- | --- |
| 歌詞の出し方を前の版に戻す | 多方向から入る文字ブロックを、中央の大きな歌詞と斜めに流れる帯へ戻した | ストーリー版の場面絵を使って、初版の文字演出を適用できた |
| ラストの芝居を見せる | 名札に目を落とす、声をかける、相手が振り向く、目が合う、の4カットを追加した | 歌詞を画面下に置き、表情が読める構図をサンプルフレームで確認した |
| 手や人物の動作を場面に合わせる | 0:29 名札を返す、0:41 鍵を受け取る、1:37 名札に書く、2:09 本音を口にする、2:53 翌朝声をかける、の5場面を差し替えた | 鍵の場面では、机上の鍵が移動し、指でつままれて持ち上がるポーズを描き分けた |

連続絵は始点と終点の間のフレームをローカルで補間した。最終版では5場面の動作を既存の場面絵と歌詞演出でつないだ。動画生成サービスへの素材アップロードはこの工程で行っていない。

## 検証記録

| 結果 | 対象 | 根拠・範囲 |
| --- | --- | --- |
| PASS | 表示用の歌詞テキスト | Sunoの登録歌詞と全46行を照合。タイミングはSunoの自動アラインメントを使用した。 |
| PASS | 最終版とアニメーション入り版の出力音声 | FFmpegでAACストリームを再エンコードせず抽出してハッシュを比較し、一致を確認した。 |
| PASS | アニメーション入り版の出力 | 1280×720、30 fps、5,892フレーム。FFmpegで映像・音声を全編デコードした。 |
| NOT_RUN | 歌唱タイミングの独立計測 | 表示タイミングのずれを人手で採点する試験は未実施。 |
| NOT_RUN | 本リポジトリの公開レンダラーでの再現 | この作品のレンダリングは、曲専用スクリプトを使用した。 |
| NOT_RUN | 既存編集手順との比較 | 編集時間、意図せず変わった範囲、第三者による再現は未測定。 |

## 次の比較試験

同じ短い区間と素材を使い、「文字の出方を前の版へ戻す」という修正指示を、普段の動画編集手順と、場面と文字を分けたスクリプト編集の両方で実施する。作業時間、作者が意図した変更の反映、対象外の映像・音声の変化を記録する。再現用の公開素材には合成音源と合成場面絵を使う。

## English summary

A 3:16 real-song MV production case documented how creator feedback changed lyric typography and five short acting sequences while preserving the exported audio stream. A one-off Python and FFmpeg workflow was used. Public renderer reproduction, independent lyric timing accuracy, and comparative editing efficiency remain untested.
